# Hospital Database Management

## About the Project

This project involved designing and developing a relational database for a hospital management system using MySQL. The aim was to organise hospital-related information and understand how relational databases can manage data efficiently.

## Key Features

- Database Design: Designed a relational database structure for hospital management.
- ERD Modelling: Created an Entity Relationship Diagram (ERD) to represent database entities and their relationships.
- Database Normalisation: Applied normalisation principles up to Third Normal Form (3NF).
- SQL Queries: Used SQL to retrieve and manage information stored in the database.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL
- Entity Relationship Diagrams (ERD)

## What I Learned

I developed practical skills in relational database design, SQL queries and database normalisation. I also gained a better understanding of how structured data can be organised and managed.
